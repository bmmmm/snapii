Image format
Output

Boxes and text become SVG shapes, so the file stays sharp at any zoom and can be edited. What cannot be drawn as shapes (images, shadows, effects) is kept as pixels. Text recognition is off in this mode.

Behavior

Runs locally; adds a few seconds to saving.

Save location

Firefox lets add-ons save only inside its Downloads folder, so this is a sub-folder name such as snapii or Pages/snapii; it is created when needed. Leave it empty for the Downloads folder itself.

Keyboard shortcut

Click the field and press the new combination. Escape cancels; Backspace or Delete removes the shortcut.
